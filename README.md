# 🎯 Duel Bullet Roulette

A simple and thrilling 2-player duel game designed for quick rounds and intense fun — all on a single device! Load your bullets, take aim, and test your luck in this digital twist on Russian roulette.

## 🕹️ Features

- 🔫 Local multiplayer: Play with a friend on the same device
- 💘 Heart-pounding visuals: Includes animations for shooting, heartbreak, and ghost effects
- 🎲 Randomized bullet logic: Danger or safety — you never know what’s coming
- 🧠 Simple mechanics: Easy to pick up, hard to put down

## 📦 Tech Stack

- **HTML**: Core structure and layout
- **CSS**: Styling and animations
- **JavaScript** *(optional)*: Game logic (if implemented)
